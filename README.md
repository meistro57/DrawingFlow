🎨 DrawingFlow

A precision-engineered workflow management system for steel fabrication shop drawings. 
Built by fabricators, for fabricators who are tired of juggling multiple Microsoft Lists 
just to track a drawing from customer request through submittal approval to the fab floor.

DrawingFlow eliminates the three-list nightmare by creating a unified pipeline:
Request → Design → Submit → Approve → Fabricate

Designed as a standalone module with future integration into the SteelFlow MRP ecosystem.

Built with ❤️ and frustration at 3 AM when another approval got lost in the shuffle.
